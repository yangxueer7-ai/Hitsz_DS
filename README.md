# 📚 Data Structures in C/C++ (学习 & 代码封装仓库)

用 C / C++ 手写并封装数据结构经典实现，配套题目练习与测试用例。  
目标：理解底层存储、掌握常见操作、形成可复用的 DS 代码库。

---

## ✨ Features
- ✅ C 风格实现（贴合教材：struct + malloc/free）
- ✅ C++ 项目中可直接编译运行（含 tests）
- ✅ 每个结构包含：初始化 / 插入 / 删除 / 查找 / 遍历 / 销毁
- ✅ 规范目录结构 + 可持续扩展

---
